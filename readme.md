# Duit Raya Calculator 🧮

Kalkulator web ringkas untuk bantu merancang agihan duit raya.

## Features
- Manual & Auto Pecah Ikut Bajet
- Randomized auto distribution
- Live ringkasan (jumlah & keping)
- Premium Raya UI (mobile-first)

## Tech Stack
- HTML
- Tailwind CSS
- Alpine.js
